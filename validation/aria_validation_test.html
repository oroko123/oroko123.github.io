Autofill Diacritic Fallback & ARIA Validation Test

Manual verification testbench for CL prototype (Idea 7: Refill diacritic-free ASCII on validation failure)

How to manually test with Chrome Autofill:

  1. Make sure Chrome is running with --enable-features=AutofillRefillAsciiOnValidationError (enabled by default in test build).
  2. Ensure you have a saved Chrome Autofill address profile containing diacritic characters:
    • Name: Przemysław Perkowski or Jérôme Dupont
    • City: München or Kraków
    • Street: Świętokrzyska 10
  3. Click into any field below and choose your profile from the Autofill popup menu.
  4. Expected Behavior:
    • Preview: The preview shows the diacritic-free ASCII fallback (e.g. Przemyslaw or Munchen) if the original violates validation constraints.
    • Fill: When filled, if verification fails and marks the field with an error / aria-invalid="true", Autofill automatically and synchronously refills the ASCII fallback.

Fields enforce strict ASCII pattern constraints: pattern="^[A-Za-z0-9\s,.-]+$". Chrome evaluates WebInputElement::IsValidValue() directly in preview and fill. When invalid, the form also sets aria-label and aria-invalid.
